# BIS Smart Grader

An AI-powered assessment platform for the BIS Faculty at Assiut University to automate the grading of handwritten English exams using Google Gemini technology.

## 👥 Authors

- **Bavly Hamdy**
- **Sama Harby**

## Features

-   **AI-Powered Grading**: Leverages Google Gemini for efficient and accurate grading of handwritten English exams.
-   **Faculty Dashboard**: A secure, protected dashboard for faculty members to manage courses, view student progress, and adjust settings.
-   **Student Portal**: A dedicated portal for students to view their exam results and feedback.
-   **Authentication**: Secure user authentication for both faculty and students.

## Technologies Used

-   **React**: Frontend library for building the user interface.
-   **React Router**: For navigation and routing within the application.
-   **Firebase**: Likely used for backend services, authentication, and database.
-   **Google Gemini API**: Powers the AI grading functionality.
-   **Vite**: Fast development build tool.
-   **Tailwind CSS**: For a utility-first CSS styling approach.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
